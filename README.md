# Cybersecurity Fundamentals Projects

A collection of Python-based cybersecurity projects developed to build and demonstrate foundational knowledge in information security, security automation, cryptography, network monitoring, and common security concepts.

These projects were developed as practical learning exercises while building a foundation in cybersecurity and ethical security practices.

## Projects

| Project                    | Description                                                                                   | Key Concepts                                     |
| -------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| **Network Tracking**       | Tracks and monitors network-related information using Python.                                 | Networking, Monitoring, Python                   |
| **File Encryptor**         | Encrypts files to demonstrate basic data protection and confidentiality concepts.             | Cryptography, File Security                      |
| **File Integrity Checker** | Verifies whether files have been modified by comparing cryptographic hashes.                  | Hashing, Integrity, File Security                |
| **Keylogger**              | Demonstrates keyboard-event monitoring in a controlled learning environment.                  | Keylogging, Input Monitoring, Security Awareness |
| **Message Encryption**     | Encrypts and decrypts messages to demonstrate secure communication concepts.                  | Cryptography, Encryption                         |
| **Password Cracking**      | Demonstrates password-guessing concepts for security testing and password-security awareness. | Authentication, Password Security                |
| **Password Generator**     | Generates random passwords designed to improve password strength.                             | Authentication, Password Security                |
| **Phishing Link Scanner**  | Analyzes URLs for potentially suspicious or phishing-related characteristics.                 | Phishing Detection, URL Analysis                 |

## Security & Ethical Use

These projects are intended for educational and authorized security-testing purposes only.

Tools that demonstrate security-sensitive techniques, such as keylogging or password-guessing, should only be executed in environments where you have explicit authorization.

Do not use these projects to monitor individuals, access systems, capture credentials, or test infrastructure without permission.
